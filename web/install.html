Binary Distribution & Lifecycle

Installation & Self-Update

Pre-compiled standalone binaries for Linux (x86_64 & ARM64), macOS (Intel & Apple Silicon), and Windows (x86_64). Keep your installation current with background update notices and ship update.

01. Automated Installers
Shell & PowerShell Distribution
curl -sSL https://raw.githubusercontent.com/dominicOT/ship/master/scripts/install.sh | bash
The shell installer auto-detects system architecture (x86_64 or aarch64/Apple Silicon) and places the ship binary in ~/.local/bin or /usr/local/bin.

03. In-Place Self-Updating (ship update)
Seamless Binary Maintenance

Passive Update Notifications

When you run ship interactively in your terminal, it occasionally checks GitHub releases in the background (cached once every 24 hours, non-blocking) and gently notifies you when a newer version is ready:

Checks
✓ tests passed
✓ secrets none found
✓ TODOs none found

✓ Ready to ship

A new version of ship is available: v0.3.5 → v0.3.7
Run `ship update` to install the latest release.

Update Commands

ship update          # download and install latest release in place
ship update --check  # check for updates without installing
ship update --force  # reinstall latest release even if current

Note: ship update manages binary installations. If you installed via cargo install --path ., update via cargo or git pull instead.
