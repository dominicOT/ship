04. Automated Diagnostic Protocols
Full 8-Module Inspection Matrix
Module Name Severity Diagnostic Scope & Action
tests CRITICAL Executes the detected project test runner (cargo test, npm test, pytest, go test). Blocks deployment with a non-zero exit code upon any test failure.
secrets CRITICAL Recursively scans source files for leaked private keys, hardcoded AWS keys, Slack webhooks, high-entropy tokens, and credentials. Non-zero exit code gates deployment.
TODOs NOTICE Scans codebase for unresolved TODO, FIXME, HACK, and XXX markers with exact filenames and line numbers.
console.logs NOTICE Identifies residual debug prints and statement leaks: console.log, dbg!, print(, println!, and fmt.Println.
feature flags NOTICE Inspects configuration toggles, temporary launch gates, and feature flags to ensure unreleased flags are reviewed before production release.
version NOTICE Audits manifest version files (Cargo.toml, package.json, pyproject.toml) and warns if manifest version is out of sync with git tags.
migrations NOTICE Detects migration frameworks (Prisma, Diesel, Django, Alembic, Goose) and checks for uncommitted schema files or pending migrations.
changelog NOTICE Verifies presence of CHANGELOG.md and validates that release notes have been recorded since the last git release tag.

07. Operating Philosophy
The Last Local Gate Before Launch

Ship is intentionally fast, small, and deterministic. It is built to serve as your final local sanity checkpoint immediately before git push or your deployment script — not as a heavy replacement for CI, but as the gatekeeper that keeps broken builds, leaked secrets, and messy debug prints from ever leaving your machine. 

ship && ./deploy.sh
# or hook into your git workflow:
ship && git push origin master
