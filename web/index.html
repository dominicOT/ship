03. Automated Diagnostic Protocols
Module Name Priority Diagnostic Scope
tests CRITICAL Runs project test suite (`cargo test`, `npm test`, `pytest`, `go test`). Non-zero exit on failure.
secrets CRITICAL Scans codebase for hardcoded API tokens, private keys, AWS secrets & high-entropy strings.
TODOs NOTICE Scans for unresolved `TODO`, `FIXME`, `HACK`, and `XXX` annotations.
console.logs NOTICE Finds leftover debug statements (`console.log`, `dbg!`, `print(`).
feature flags NOTICE Detects unmerged temporary feature flags and toggles.
migrations NOTICE Audits database migration sync status (Prisma, Diesel, Alembic, etc).
